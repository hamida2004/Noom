# Privacy Policy — NOOM

*Last updated: May 2026*

Welcome to **NOOM**, a smart sleep monitoring and intelligent alarm application designed to improve wake-up timing using physiological and movement signals collected from wearable devices.

By using NOOM, you agree to the practices described in this Privacy Policy.

---

# 1. Information We Collect

NOOM may collect and process the following categories of information:

## Sleep and Sensor Data

When connected to a compatible wearable device, NOOM may collect:

* Accelerometer (ACC) data
* Heart rate (HR)
* Blood volume pulse (BVP)
* Inter-beat interval (IBI)
* Temperature measurements
* Sleep stage predictions
* Alarm timing and wake-up events

This data is used exclusively to:

* estimate sleep stages,
* optimize alarm timing,
* improve user experience,
* and generate sleep-related insights.

---

# 2. User Preferences and Local Storage

NOOM stores certain information locally on your device, including:

* alarm settings,
* calibration parameters,
* session history,
* wake-up ratings,
* application preferences.

This information is stored using secure local application storage mechanisms.

---

# 3. How We Use Your Data

Your data may be used to:

* operate the smart alarm system,
* analyze sleep-related patterns,
* personalize wake-up timing,
* improve algorithm performance,
* debug and enhance application stability.

NOOM does not sell personal data to third parties.
